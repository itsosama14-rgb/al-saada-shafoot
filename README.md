# مطعم السعادة شعفوط

موقع طلبات إلكتروني عربي مع قائمة طعام ديناميكية ولوحة إدارة للطلبات والمنيو.

## التقنية
- Next.js 15
- Upstash Redis REST لحفظ الطلبات وأصناف المنيو والأقسام
- Vercel للنشر

## إعداد متغيرات البيئة
أضف المتغيرات التالية في إعدادات المشروع على Vercel (Settings → Environment Variables):

- `UPSTASH_REDIS_REST_URL`: رابط قاعدة Upstash Redis REST.
- `UPSTASH_REDIS_REST_TOKEN`: رمز الوصول الخاص بقاعدة Upstash.
- `ADMIN_PASSWORD`: كلمة مرور قوية وخاصة بلوحة الإدارة.

لا تضع هذه القيم في ملفات عامة أو تشاركها مع العملاء. بعد إضافتها أعد نشر المشروع.

## إدارة المنيو
افتح `/admin/menu` وسجّل الدخول باستخدام `ADMIN_PASSWORD`. يمكنك إضافة الأصناف وتعديلها وحذفها، وتغيير السعر والوصف والقسم والصورة (عبر رابط صورة HTTPS)، وإيقاف الصنف مؤقتاً دون حذفه، وإضافة الأقسام وحذف الأقسام الفارغة.

تُحفظ البيانات في Upstash Redis، وتقرأ واجهة الزوار القائمة من `/api/menu` وتحدّثها تلقائياً كل 15 ثانية. يتحقق الخادم من السعر الحالي من قاعدة البيانات عند إنشاء الطلب.

## إدارة الطلبات
افتح `/admin` لإدارة الطلبات وتحديث حالتها.
